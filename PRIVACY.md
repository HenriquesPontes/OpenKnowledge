## Data this product handles

- **Waitlists** — email and which waitlist you joined (Open Knowledge, Connect, dictionaries, API Platform) so we can notify you.
- **API Platform accounts** — email, authentication credentials, optional registration codes; keys to operate the Linguistic Research API client identity.
- **Technical logs** — IP and request metadata for security, reliability, and abuse prevention on this site.

Linguistic Research lexicons shown on this site are language documentation, not end-user personal profiles. We do not use the public research API to build advertising profiles.

Learning app on-device data is covered in the Learning pillars’ `PRIVACY.md` files, not here.
